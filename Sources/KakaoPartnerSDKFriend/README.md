# KakaoPartnerSDKFriend

파트너용 피커 인터페이스 모듈입니다.

## Requirements
- iOS 15.0
- Swift 5.8

## Dependencies
- KakaoSDKFriend
- KakaoPartnerSDKCommon

## Installation
```swift
.package(url: "https://github.com/kakao/kakao-partner-ios-sdk.git", from: "2.0.0")
```
2.x.x 버전을 사용합니다. 타겟의 Dependencies에 `KakaoPartnerSDKFriend`을 추가합니다.

## Import
```
import KakaoPartnerSDKFriend
```
